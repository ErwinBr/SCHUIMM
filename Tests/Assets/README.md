# Test assets

Checked-in files used by the unit tests. The tests receive this directory as an absolute path
(`SCHUIMM_TEST_ASSET_DIR`), so they do not depend on the working directory.

`Images/` is generated by [`generate_test_images.py`](generate_test_images.py) (Python standard
library only). Re-run it to reproduce the files exactly; the expected pixel values in
`Tests/Resource/ImageDecoderTests.cpp` are the ones written by the script.

| File | Covers |
|---|---|
| `rgba_4x2.png` | RGBA8: exact dimensions, format and pixels; alpha 255, 128, 40 and 0; colour kept under alpha 0 |
| `rgb_3x1.png` | RGB8 without alpha becomes alpha 255 |
| `palette_trns_2x2.png` | palette image with `tRNS` transparency (opaque, half, fully transparent entries) |
| `gray_alpha_2x1.png` | greyscale + alpha |
| `gray1_8x1.png` | 1-bit greyscale |
| `rgba16_2x1.png` | 16-bit RGBA with an `sRGB` chunk, reduced to 8 bits |
| `interlaced_rgba_5x5.png` | Adam7 interlacing |
| `not_an_image.png` | text with a `.png` name: unrecognised format |
| `truncated.png` | first half of `rgba_4x2.png` |
| `corrupt_crc.png` | `rgba_4x2.png` with one byte of compressed data flipped (CRC mismatch) |

`Audio/` is generated by [`generate_test_sounds.py`](generate_test_sounds.py) (standard library
only); the expected samples in `Tests/Resource/WavDecoderTests.cpp` are the ones it writes.

| File | Covers |
|---|---|
| `mono16_8k.wav` | 16-bit mono PCM: exact samples incl. full scale, and an odd-sized `LIST` chunk before the data that must be skipped |
| `stereo8_22k.wav` | 8-bit unsigned stereo |
| `mono24_44k.wav` | 24-bit signed (sign extension) |
| `stereo_float_48k.wav` | 32-bit IEEE float |
| `extensible16.wav` | `WAVE_FORMAT_EXTENSIBLE` with a PCM sub-format |
| `adpcm.wav` | unsupported codec (IMA ADPCM) |
| `three_channels.wav` | unsupported channel count |
| `truncated.wav` | data chunk longer than the file |
| `not_a_sound.wav` | text with a `.wav` name |

Font tests use the EngineDemo's `Assets/Fonts/NotoSans-Regular.ttf` instead of a copy.
